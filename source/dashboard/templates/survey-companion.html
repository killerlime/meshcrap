Meshcrap Survey · Android phone setup

First test build. Software checks have run; the Bluetooth connection still needs verification on your phone and radio. Automatic traceroutes start disabled.

1. Install the private survey app

{% if apk_available %}

Download Meshcrap Survey APK

{% else %}

Build the Android project included in this repository and install its APK on your phone. See the repository README for build and optional download-hosting instructions.

{% endif %}

Use Android 8 or later. Your phone must reach the collector through trusted HTTPS, for example over Tailscale. The app connects directly to an already-paired radio: disconnect the Meshtastic app from that radio first.

2. Pair it with your collector

Open this private HTTPS setup page, unlock Receiver admin controls in the same browser, then return here. The pairing code is for survey uploads only; it is not a radio admin key.

Generating a new code replaces the previous phone pairing. Saved results on the phone remain available for upload after re-pairing.

3. Verify one traceroute

  1. Paste the pairing code into Meshcrap Survey. Allow Bluetooth and location, list paired radios, and connect your chosen local radio.
  2. Confirm the node name, ID and channel shown in the app. Choose the appropriate channel if needed.
  3. On the website, select a coverage area and start a coverage survey.
  4. In Meshcrap Survey, choose one nearby destination and send a test traceroute. Wait for a successful response before enabling the nearby-node survey.

The app requires a recent position and recently heard destinations with known positions. It starts with a 10-mile radius, adjustable on the phone.

During your outing

One request at a time, at least two minutes apart, with up to five minutes for a response. Each candidate is tried once per outing. Requests pause if Bluetooth or the collector connection is lost. A lost connection may take up to 30 seconds to expire.

Use the notification’s Pause or Stop controls. Stop releases Bluetooth so you can reconnect Meshtastic. Saved results upload on the next connection; no uncertain request is automatically resent after a restart.

Phone GPS records your path. It does not automatically turn a cell into proven RF coverage. Phone traceroutes are stored separately from measurements heard by Receiver.
